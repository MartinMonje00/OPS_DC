# OPS_DC
Sitio WEB para el manejo de DataCenters principalmente creado por Roberto Carmona Claro y reconstruido por Martin Monje Álvarez en Ionic Framework con el fin de que se pueda utilizar en PC's de Escritorio, como y para algunos casos, en algunas tablets

# Requerimientos e Instalaciones

## Requisitos previos
Para requisitos previos, se necesita estas instalaciones al probar en estado de Desarrollo
 - Node.js versión 26.4.0.
 - Angular CLI versión 22.0.5.
 - Ionic CLI versión 7.2.1.
 - chart.js version 4.5.1.
 - jwt-decode version 4.0.0.
 - API personalizada para el proyecto.
 - Navegador local.
